O estúdio

Jogo bom é jogo que responde bem

Somos seis pessoas construindo nossos primeiros títulos e a identidade da Scorpion Bits na indústria. Três coisas guiam tudo que fazemos:

Mecânicas polidas

Preferimos poucas mecânicas bem resolvidas a uma lista grande de recursos pela metade. Cada sistema é testado até parecer óbvio na mão de quem joga.

Game feel responsivo

Peso, aceleração, recuo, pausa de impacto. É o que separa um comando que funciona de um comando que dá vontade de repetir.

Direção de arte própria

Arte e som feitos internamente, do sprite ao trilha sonora, para que cada projeto tenha uma cara que só ele tem.

Educação

Curso de desenvolvimento de jogos no SESC

A Scorpion Bits foi contratada pelo SESC para levar a turma GameLab do zero absoluto até um jogo 2D top-down completo na engine Godot. A maioria dos alunos nunca programou antes — então o material foi escrito do começo, por nós, pensando exatamente nisso.
